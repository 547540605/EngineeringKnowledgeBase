# 机器人力控制算法分类：NISTIR 7901 的 A–F 方法

## 领域归属

- 主领域：Engineering / Robotics / Force Control。
- 上游知识：反馈控制、机器人运动学与动力学、力/力矩传感、位置/速度/力矩控制接口。
- 相关知识：[显式力控制与闭环控制系统框图](Explicit-Force-Control-Closed-Loop.md)、阻抗控制、导纳控制、机器人刚度控制、接触力学。
- 下游应用：恒力压合、表面跟随、磨抛、Peg-in-Hole、USB/连接器插拔和其他接触装配。

## 分类依据与阅读方法

NISTIR 7901 Section V 将显式力控制、刚度控制、阻抗控制、导纳/顺应控制、隐式力控制和自然导纳控制列为主要力控算法类型。读这些分类时，关键不是记住名称，而是问三个问题：**系统测量什么，力与运动状态之间建立了什么关系，控制器最终向机器人输出什么量？**

这些是文献中的概念类别，不是保证互斥的产品规格。同一机器人可能组合多种关系和底层伺服环，不同文献也可能对相同术语采用不同数学定义。下文把 NIST 的描述和便于理解的直觉分开写；示意关系不等于该报告对所有实现规定的控制方程。

## A. 显式力控制（Explicit Force Control）

测得的力进入反馈回路，与目标/命令力比较形成误差，再据此调整施力命令。NIST 用 PI 方框图说明比例、积分增益如何影响力误差的收敛。其框图、信号符号及与单轴恒力 Demo 的对应关系，见[显式力控制与闭环控制系统框图](Explicit-Force-Control-Closed-Loop.md)；其中的交互式 PI 仿真是理想对象演示，并非设备实测。

## B. 刚度控制（Stiffness Control）

刚度控制让机器人或工具表现得像弹簧：偏离参考位置越多，产生的恢复力越大。沿单轴的理想弹簧可写成 $F=-k\Delta x$，其中 $\Delta x$ 是相对参考位置的位移、$k$ 是刚度，负号表示恢复力方向与偏移相反；阻尼器可以同时用于减缓运动和冲击。

它可以是**被动刚度**——在末端与工具之间实际安装弹簧、阻尼器或 RCC 等柔顺机构；也可以是**主动刚度**——通过力反馈把机器人控制成可调的“程序化弹簧”。NIST 指出，被动机构可补偿插入时的小姿态误差；主动刚度更适合重视力测量精度的低带宽应用。弹簧类比用于理解输入输出关系，不是报告给出的唯一控制方程。

## C. 阻抗控制（Impedance Control）

机械阻抗描述运动与力之间的动态关系。NIST 在本节用操作者运动输入、机器人反馈反作用力的交互来介绍阻抗，并概括为维持 TCP 位置与作用力等变量之间的动态关系，而不是孤立地控制某一个变量。直观上，它规定“发生某种运动或偏差时，系统呈现出怎样的力学响应”。

报告指出，阻抗控制可以在与刚性物体接触时实现较高带宽的力响应，常用于抛光、材料去除和部分装配任务。阅读其他文献时要留意定义边界：有些资料会以“位移/速度偏差产生力响应”来描述机器人阻抗控制；NIST 此处的操作者交互表述是其具体介绍视角，不能仅凭算法名称推断某个设备内部的实现。

## D. 导纳／顺应控制（Admittance / Accommodation Control）

导纳/顺应控制与阻抗的输入输出方向相反：测得的外力被转换为机器人运动响应，简化地说是“力输入 → 速度或位移响应”。控制器可以通过调整等效刚度和阻尼，改变末端对外力的让步程度及运动快慢。

这类实现常见于机器人本身的位置/速度接口可用、但没有直接力矩控制接口的场景：外部力传感器测到推力后，控制器计算运动修正，再交给底层运动接口执行。这里描述的是常见实现形态；具体系统还要检查采样、滤波和内层位置/速度环。

## E. 隐式力控制（Implicit Force Control）

隐式力控制在运行时**没有外部力传感器的直接力反馈闭环**。它利用已有模型或标定关系，从关节电流、关节力矩等信息推断末端大致承受的力；NIST 也举出弹性关节机器人按预设位置运动、再依据先前测量推断作用力的例子。外部力传感器仍可用于建立或校准推断关系，但不等于其实时读数正在闭环中直接调节运动。

这种方法可减少对专用末端力传感器的依赖；限制是推断结果依赖模型和标定，零件变化、编码器漂移等会降低可靠性。实际使用还应评估摩擦、惯性、温漂和动态工况对电流/力矩估计的影响——这些是应用时需要额外验证的工程因素，不是报告对每种实现的统一保证。

## F. 自然导纳控制（Natural Admittance Control）

自然导纳控制也使用虚拟弹簧和阻尼器，但 NIST 特别强调一个**相对工具坐标系固定的参考点/虚拟吸引点**。物理接触力与虚拟弹簧、阻尼产生的作用共同影响机器人；机器人按合力方向、结合自身惯量的逆来加速，使末端呈现稳定且有响应性的交互。

可以把它想成末端被一根可调的“虚拟弹簧—阻尼器”牵向工具坐标系中的参考点，同时接触力会改变合力和运动。虚拟吸引点是理解 F 与一般导纳描述的一个关键线索；实际算法的状态、坐标变换、质量/阻尼参数和离散实现仍须以具体论文或控制器文档为准。以上是对 NIST 概述的解释，不是报告原文中的统一数学模型。

## A–F 快速对照

| 类别 | 主要关系／信号方向 | 阅读时抓住的要点 |
| --- | --- | --- |
| A 显式力控制 | 测量力与目标/命令力比较 → 力误差闭环 | 外部测得的力直接参与反馈 |
| B 刚度控制 | 位移偏差与恢复力（弹簧行为） | 柔顺可来自真实机械结构，也可由力反馈主动实现 |
| C 阻抗控制 | 运动状态与反作用力之间的动态关系 | 关注接触时系统“呈现什么力学行为”；NIST 还用操作者交互解释 |
| D 导纳／顺应控制 | 外力测量 → 运动响应 | 力被转换成速度/位置修正，通常还依赖底层运动环 |
| E 隐式力控制 | 电流/关节力矩/模型 → 推断力 | 运行时不直接把外置力传感器读数作为闭环反馈 |
| F 自然导纳控制 | 接触力与虚拟弹簧/阻尼/吸引点共同作用 → 加速度 | 特别关注工具坐标系中的参考吸引点和合力响应 |

这些类别不应机械地视为互斥标签：系统可能组合刚度、阻尼、力反馈和运动内环；同一名称在不同文献中的数学结构也可能不同。比较方案时，应把传感量、误差/状态、控制器输出和底层机器人接口画清楚，而不是只看算法名。

## 与恒力 Demo 和 USB 插拔的联系

当前恒力 Demo 的控制链是“力误差 → PID → Z 轴速度命令”。因此，它的外层输入输出关系与导纳/顺应的“力影响运动”直觉相近，但这**不足以单独证明 Demo 实现了标准导纳控制**：还需检查速度命令如何作用于机器人、内环结构、坐标方向、采样延迟及接触模型。它也不同于 NIST A 节中 PI 直接形成命令力的示意。

恒力压合主要关注沿指定方向把接触力稳定在目标附近；USB 插拔则还要解决端口对准、接触/卡边识别、搜索方向、姿态调整、插入完成判定和卡滞恢复。阻抗/导纳等柔顺关系可以帮助插头在接触时让步或调整，但它们本身不等于完整的插拔策略，也不保证仅靠一个力传感器就能判断插入成功。更大的学习脉络见[机器人恒力控制与柔顺装配学习路线](Robot-Force-Control-and-Compliant-Assembly-Learning-Path.md)。
