# RS485 差分信号、半双工与总线连接

## 所属领域

```text
Computer Science
└─ Networking
   └─ Serial Communication
      └─ RS485 Physical Layer
```

RS485 主要规定电气信号如何在线路上传输。它不规定报文中的设备地址、功能码和寄存器含义，这些属于 Modbus RTU 等上层协议。

## 从程序到线路的完整位置

```text
C# 程序准备 byte[]
        ↓
串口/UART 按 115200 8N1 逐位发送
        ↓
RS485 收发器把逻辑电平转换为 A/B 差分信号
        ↓
双绞线传输
        ↓
夹爪的 RS485 收发器还原逻辑位
        ↓
夹爪按 Modbus RTU 解析字节
```

程序通常只面对 COM 口和字节数组；USB 转 RS485 转换器负责 USB、串口和 RS485 电气信号之间的转换。

## UART、TTL 串口、RS232 和 RS485

这些名称描述的层面不同：

| 名称 | 主要含义 |
| --- | --- |
| UART | 将字节转换为异步串行 bit，并处理起始位、校验位、停止位 |
| TTL UART | 使用常见 3.3V 或 5V 单端逻辑电平传输 UART 信号 |
| RS232 | 使用 RS232 电气电平，通常点对点通信 |
| RS485 | 使用差分电气信号，可组成多设备总线，适合较远距离和工业环境 |

它们不能只因为都使用 `115200 8N1` 就直接互相接线。电气标准不兼容时需要对应的收发器或转换器。

## 什么是差分信号

RS485 使用 A、B 两根线共同表达一个逻辑状态。接收方主要判断两根线之间的电压差，而不是只判断某一根线相对地的电压。

可以抽象理解为：

```text
状态一：A 相对 B 更高
状态二：B 相对 A 更高
```

实际哪个状态对应逻辑 0 或 1，以及 A/B 与 `+/-` 的标注，行业设备之间可能存在命名差异。接线时应以双方设备说明书和端子定义为准，不应只凭字母猜极性。

## 为什么差分传输抗干扰

若外界干扰同时让 A、B 两根线都升高相近电压：

```text
干扰前：A - B = 某个有效电压差
干扰后：A 和 B 同时升高，A - B 仍接近原值
```

接收方关注的是两线之差，因此共同叠加到两根线上的干扰有机会被抵消。这称为共模干扰抑制。

A、B 通常使用双绞线，让两根线受到的外界干扰尽量相近，从而发挥差分传输优势。

## 两线半双工

常见的两线 RS485 使用同一对 A/B 线进行发送和接收，因此某个时刻通常只能有一方驱动总线：

```text
主站发送请求
    ↓
主站停止发送并释放总线
    ↓
对应从站发送响应
    ↓
从站停止发送并释放总线
```

这种“双方都能发送，但不能同时发送”的方式称为半双工。

若双方同时驱动 A/B 线，可能发生总线冲突，导致报文损坏。Modbus RTU 使用主站请求、从站响应的流程，正好适合这种通信方式。

## 主站、从站与设备地址

在本项目中可以理解为：

```text
MaterialTable 服务：主站
EPG-HP 夹爪：       从站
```

主站主动发送请求，从站通常只在收到发给自己的有效请求后响应。

多个夹爪连接到同一条 RS485 总线时，所有设备都能看到线路上的请求，但只有设备地址匹配的从站应当响应。因此每个从站地址必须唯一。

主站、从站和设备地址主要是 Modbus RTU 的通信组织方式，不是 RS485 电气标准本身规定的业务角色。

## 总线拓扑

RS485 通常推荐沿一条主干线依次连接设备：

```text
主站 ───── 从站1 ───── 从站2 ───── 从站3
```

这种方式常称为总线型或菊花链连接。设备到主干线的支线应尽量短。

不推荐从中心分出多条很长的星形支路：

```text
          ┌─ 从站1
主站 ─────┼─ 从站2
          └─ 从站3
```

长支路和分叉会增加信号反射，通信速度越高、线路越长，问题越明显。

## 120Ω 终端电阻

长线传输时，电信号到达线路末端可能发生反射，反射信号会干扰后续数据。终端电阻用于让线路末端的阻抗与电缆特性更匹配，减小反射。

典型做法是在整条总线的两个物理末端各连接一个约 120Ω 的终端电阻：

```text
[120Ω] 主站 ───── 从站1 ───── 从站2 [120Ω]
```

不是每个设备都加一个终端电阻。短距离、低干扰环境中没有终端电阻也可能正常通信，但工程配置应结合设备说明书、线长、波特率和现场测试确定。

## A/B 接反会怎样

A、B 接反后，接收方看到的差分极性相反，通常表现为：

```text
完全收不到有效响应
持续超时
收到校验错误或乱码
```

由于不同厂商对 A/B、D+/D- 的命名可能不完全统一，应优先按两边说明书核对。确认供电和其他接线正确后仍无法通信，可以在断电并确保安全的条件下交换 A、B 进行排查。

本项目夹爪说明书给出的线色为：

```text
RS485 A：白色
RS485 B：黑色
```

## 是否需要连接参考地

RS485 使用差分信号，但收发器允许的共模电压范围仍有限。设备之间地电位差过大可能导致通信不稳定甚至损坏接口。

是否连接通信参考地、屏蔽层如何接地，以及是否需要隔离，应遵循设备和转换器说明书。工业现场存在较大地电位差时，优先考虑隔离型 RS485 转换器，而不是随意连接保护地或屏蔽层。

## 电脑如何连接夹爪

普通电脑通常没有原生 RS485 端口，常见链路为：

```text
MaterialTable 程序
    ↓
Windows COM 口
    ↓
USB 转 RS485 转换器
    ↓
A/B 双绞线
    ↓
EPG-HP 夹爪
```

程序打开的是类似 `COM3` 的串口，配置 `115200 8N1`，再发送 Modbus RTU 字节。转换器负责控制 RS485 的收发方向；具体产品是否自动切换方向应查看转换器说明。

## 当前阶段应掌握

1. RS485 主要规定电气传输，不解释 Modbus 报文含义。
2. A、B 使用差分信号，通常应采用双绞线。
3. 两线 RS485 通常是半双工，主站和从站不能同时发送。
4. 多个从站可以共用总线，但 Modbus 设备地址必须唯一。
5. 终端电阻通常只放在总线两个物理末端。
6. A/B 命名可能存在厂商差异，应以设备说明书和实测为准。
