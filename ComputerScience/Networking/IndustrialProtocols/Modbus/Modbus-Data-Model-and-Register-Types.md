# Modbus 数据模型与寄存器类型

## 所属领域

```text
Computer Science
└─ Networking
   └─ Industrial Protocols
      └─ Modbus
         └─ Data Model
```

Modbus 把设备对外提供的数据按“数据宽度”和“是否允许主站写入”分为四类。这个模型源于 PLC，但现代传感器、执行器和夹爪也会用它描述自己的通信接口。

## 四类数据区域

| 数据类型 | 单个数据宽度 | 主站权限 | 常用功能码 | 常见用途 |
| --- | --- | --- | --- | --- |
| Coil（线圈） | 1 bit | 读写 | `0x01`、`0x05`、`0x0F` | 开关命令、启停标志 |
| Discrete Input（离散输入） | 1 bit | 只读 | `0x02` | 限位、传感器开关状态 |
| Input Register（输入寄存器） | 16 bit | 只读 | `0x04` | 位置、温度、电压、故障反馈 |
| Holding Register（保持寄存器） | 16 bit | 读写 | `0x03`、`0x06`、`0x10` | 参数、目标值、控制命令 |

这里的“输入”是从设备角度命名：数据由现场或设备内部产生，并提供给主站读取。它不是说主站要向输入寄存器写入数据。

## 为什么要分成四类

### 数据宽度不同

开关量只有两种状态，用 1 bit 就够了：

```text
0 = 关闭
1 = 开启
```

位置、速度、温度和电压等数值需要更大范围，通常使用 16 bit 寄存器。

### 读写权限不同

设备状态通常由设备自己产生，主站只能读取：

```text
当前位置
当前温度
当前故障
是否检测到工件
```

控制参数由主站下发，需要允许写入：

```text
目标位置
运行速度
夹持力
使能或动作命令
```

把两者分开，可以明确谁负责修改数据，也能减少误写设备反馈状态的机会。

### 操作语义不同

功能码同时表达了“访问哪一类数据”和“执行读还是写”。例如：

```text
0x03：读取保持寄存器
0x04：读取输入寄存器
0x06：写一个保持寄存器
0x10：写多个保持寄存器
```

即使偏移地址相同，使用不同功能码也可能访问不同的数据区域，因此功能码和地址必须一起理解。

## 保持寄存器的“保持”是什么意思

“保持寄存器”是 Modbus 的历史名称，表示一类可由主站读写的 16 位数据区域。它不自动保证设备断电后数据仍然保存。

参数是否写入非易失存储器、断电后是否保留，要看具体设备说明书，不能只凭 Holding Register 这个名称判断。

## 寄存器不是 CPU 寄存器

Modbus 寄存器是设备通过协议公开的逻辑数据槽，通常按 16 bit 编号。它不一定与设备处理器内部真实的 CPU 寄存器一一对应。

设备固件可能把多个内部变量整理、换算或打包后，再映射为 Modbus 寄存器供外部访问。

## 为什么夹爪还需要很多寄存器地址

数据类型只决定基本宽度和权限，具体设备仍需为每项功能分配地址。例如电动夹爪可能公开：

```text
控制区域
├─ 使能和动作命令
├─ 控制模式
├─ 目标位置
├─ 目标速度
└─ 目标夹持力

反馈区域
├─ 当前状态
├─ 是否检测到工件
├─ 当前位置
├─ 当前故障
├─ 当前电压
└─ 当前温度
```

一个 16 位寄存器只有 16 bit，不能在含义清楚、范围足够的前提下容纳所有数据。将不同功能分配到不同地址还可以明确数据格式、范围、读写权限和更新时机。

一些只占 0/1 的状态会被打包到同一个寄存器的不同比特中，以节省地址：

```text
bit0：是否使能
bit1：动作是否完成
bit2：是否检测到工件
bit3：是否故障
```

这就需要使用位掩码提取具体状态。

## EPG-HP 夹爪中的对应关系

说明书把主要数据分为控制和状态反馈两类：

```text
控制寄存器首地址：0x03E8
状态寄存器首地址：0x07D0
```

可以从职责上理解为：

```text
控制区：主站告诉夹爪要做什么
反馈区：夹爪告诉主站现在怎么样
```

实际使用哪一个功能码、字段是否可写、每个 bit 或 byte 的含义，必须以夹爪说明书对应表格为准。

## 地址表示法容易混淆

传统 Modbus 文档有时使用 `0xxxx`、`1xxxx`、`3xxxx`、`4xxxx` 表示四类数据区域，例如 `40001` 常用于表示第一个保持寄存器。

这种“参考编号”不是 RTU 报文里直接发送的 16 位地址。报文通常发送该数据区域内的地址偏移，而且不同文档可能采用从 0 或从 1 开始的写法。

另外，十六进制地址 `0x03E8` 前面的 `03` 只是数值的一部分，不能因为它以 `03` 开头就判断它属于输入寄存器。寄存器类型应根据功能码和设备说明书判断。

## 当前阶段应掌握

1. 线圈和离散输入是 1 bit 数据。
2. 输入寄存器和保持寄存器通常是 16 bit 数据。
3. 输入寄存器通常由设备产生、供主站只读。
4. 保持寄存器通常允许主站读写，但不保证断电保存。
5. 功能码和地址共同确定访问的对象。
6. 设备需要多个地址，是因为它要公开许多不同含义、范围和权限的数据。
