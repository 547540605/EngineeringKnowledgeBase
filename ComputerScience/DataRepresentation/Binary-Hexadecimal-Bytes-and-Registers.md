## 同一个数值的不同写法

十进制、二进制和十六进制只是表示方式不同，数值本身没有变化。

| 十进制 | 二进制 | 十六进制 |
| --- | --- | --- |
| `9` | `1001` | `0x9` |
| `10` | `1010` | `0xA` |
| `15` | `1111` | `0xF` |
| `16` | `0001 0000` | `0x10` |
| `255` | `1111 1111` | `0xFF` |

在 C# 等编程语言中，前缀 `0x` 表示后面的数字采用十六进制书写。

## 为什么硬件协议常用十六进制

一个二进制位称为 `bit`，只能是 0 或 1。四个 bit 恰好对应一个十六进制数字：

```text
1010 = A
1111 = F
```

一个字节包含 8 bit，因此可以由两个十六进制数字完整表示：

```text
二进制：1111 1111
十六进制：   F    F
```

十六进制比二进制短，同时能清楚地对应底层字节，所以硬件说明书和通信报文经常采用十六进制。

## bit、byte 和数值范围

```text
1 bit  = 1 个二进制位
1 byte = 8 bit
2 byte = 16 bit
```

| 位数 | 无符号最小值 | 无符号最大值 | 十六进制范围 |
| --- | ---: | ---: | --- |
| 8 bit | 0 | 255 | `0x00`～`0xFF` |
| 16 bit | 0 | 65535 | `0x0000`～`0xFFFF` |

`n` 个 bit 能组合出 `2^n` 种状态。因为从 0 开始，最大无符号值是 `2^n - 1`。

## 16 位寄存器

Modbus 中一个寄存器通常是 16 bit，也就是两个字节：

```text
16 bit 寄存器
┌──────────────┬──────────────┐
│ 高字节 8 bit │ 低字节 8 bit │
└──────────────┴──────────────┘
```

夹爪说明书给出的控制寄存器首地址是 `0x03E8`，它可以拆成：

```text
高字节：0x03
低字节：0xE8
```

其十进制值是：

```text
0x03E8
= 3 × 16² + 14 × 16¹ + 8 × 16⁰
= 768 + 224 + 8
= 1000
```

这里的 `0x03E8` 是寄存器地址，而不是寄存器中保存的数据：

```text
寄存器地址：去哪里读写
寄存器数据：那个位置当前保存了什么
```

可以把寄存器理解成一排带编号的格子：

```text
地址 0x03E8 → [数据]
地址 0x03E9 → [数据]
地址 0x03EA → [数据]
```

## 高字节与低字节

在 C# 中拆分一个 16 位数：

```csharp
ushort value = 0x03E8;

byte highByte = (byte)(value >> 8);
byte lowByte = (byte)(value & 0xFF);
```

重新组合：

```csharp
ushort value = (ushort)((highByte << 8) | lowByte);
```

其中 `>>`、`<<`、`&` 和 `|` 是位运算，后续学习状态位和 Modbus 报文时会继续展开。

## 十六进制不代表业务含义

看到十六进制数字时，必须结合它在报文中的位置和设备说明书判断含义：

```text
0x09   可能是从站地址
0x03   可能是功能码
0x03E8 可能是寄存器地址
0x0001 可能是寄存器数据
0xA1B2 可能是 CRC 校验值
```

它们都用十六进制书写，但含义完全不同。

## C# 基本类型对应

| C# 类型 | 位数 | 常见用途 |
| --- | ---: | --- |
| `byte` | 8 bit | 单个报文字节 |
| `sbyte` | 8 bit | 有符号单字节数值 |
| `ushort` | 16 bit | 无符号寄存器数据或地址 |
| `short` | 16 bit | 可能为负数的寄存器数据 |
| `uint` | 32 bit | 两个寄存器组合的无符号数据 |
| `int` | 32 bit | 两个寄存器组合的有符号数据 |

具体选择有符号还是无符号类型，必须根据设备说明书对字段的定义判断。

## 当前阶段应掌握

1. `0x` 表示十六进制写法。
2. 1 byte 等于 8 bit，两个十六进制数字表示一个 byte。
3. Modbus 中一个寄存器通常是 16 bit，即两个 byte。
4. `0x03E8` 等于十进制 1000，可拆成 `0x03` 和 `0xE8`。
5. 寄存器地址与寄存器数据是两件事。
6. 十六进制只是一种写法，不能单凭写法判断业务含义。
